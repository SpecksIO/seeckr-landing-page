# SEO et GEO : fiche de démarrage

Laureline, ce dossier contient ton travail sur le référencement de seeckr.fr, dans Google (SEO) comme dans les assistants
IA comme ChatGPT (GEO). Tu travailles avec Claude Code, qui s'occupe de toute la partie technique. Toi, tu décides du fond.

## Une seule fois : l'installation

1. Demande à Amandine de t'ajouter au dépôt GitHub `SpecksIO/seeckr-landing-page`. Crée un compte GitHub si tu n'en as
   pas.
2. Installe Visual Studio Code : <https://code.visualstudio.com/>.
3. Installe Git : <https://git-scm.com/downloads>.
4. Dans Visual Studio Code, installe l'extension Claude Code et connecte-toi avec ton compte Claude :
   <https://code.claude.com/docs/en/vs-code>.
5. Dans Visual Studio Code, choisis « Cloner le dépôt Git », colle `https://github.com/SpecksIO/seeckr-landing-page`,
   puis connecte-toi à GitHub quand il te le demande.

Le reste s'installe tout seul à ta première séance.

## Chaque séance

Ouvre le dossier `seeckr-landing-page` dans Visual Studio Code, ouvre Claude Code et tape `/seo-geo`. Claude met ton poste
à jour, regarde où en est le travail, et te propose le programme de la journée. Tu choisis, il enchaîne.

Tu peux aussi lui parler normalement : « écris le prochain guide », « on fait le panel du mois », « à qui j'écris cette
semaine ? ».

## Quand Claude te donne un prompt à coller

Deux outils ne sont accessibles que depuis ton Claude sur navigateur : le projet Seeckr, et ton outil de posts LinkedIn.
Quand Claude Code te donne un texte dans un encadré, colle-le dans l'outil qu'il te nomme, puis recolle la réponse
dans Claude Code.

## Trois règles

- Tu publies seule. Claude vérifie chaque fait avant la mise en ligne. S'il retire une phrase faute de source, c'est
  voulu.
- Quand Claude écrit « préviens Amandine », fais-le et passe à autre chose : ce n'est pas à toi de réparer le site.
- Les messages aux sites extérieurs partent de ta messagerie, jamais de Claude. Relis-les avant envoi.
