# Fiche type pour les annuaires

Les champs à copier dans chaque formulaire d'annuaire. Tout vient de `src/content/fr/` : aucun chiffre, aucune fonctionnalité qui ne soit pas sur le site. Pas de « +15 % » tant que la mesure n'est pas validée (voir « Pour Amandine » dans `seo/backlog.md`).

| Champ | Contenu |
| ----- | ------- |
| Nom | Seeckr |
| Site web | https://seeckr.fr |
| Accroche (160 caractères au plus) | Seeckr est un conseiller produit IA pour sites e-commerce : il interroge chaque visiteur comme un vendeur en boutique, puis lui recommande son top 3. |
| Description longue | Seeckr est un assistant IA qui pose quelques questions à vos visiteurs, comme le ferait un vendeur en boutique, puis leur recommande les produits de votre catalogue qui correspondent à leur besoin. Le visiteur décrit sa situation sans avoir à connaître le nom du produit. Il reçoit un top 3 classé, avec un score de compatibilité et la raison de chaque place. Si un seul produit lui convient, l'assistant n'en propose qu'un ; si aucun ne convient, il le dit. Le marchand relit chaque conversation, avec les mots de ses clients. Seeckr s'installe avec une ligne de script, se connecte à toutes les plateformes e-commerce (Shopify, WooCommerce, PrestaShop, sites sur mesure) et parle neuf langues. |
| Catégorie | la plus proche de « e-commerce » ; sinon « vente », puis « assistant IA » |
