# Fiche type pour les annuaires

Les champs à copier dans chaque formulaire d'annuaire. Tout vient de `src/content/fr/` : aucun chiffre, aucune fonctionnalité qui ne soit pas sur le site. Pas de « +15 % » tant que la mesure n'est pas validée (voir « Pour Amandine » dans `seo/backlog.md`).

| Champ | Contenu |
| ----- | ------- |
| Nom | Seeckr |
| Site web | https://seeckr.fr |
| Accroche (160 caractères au plus) | Seeckr est un conseiller produit IA pour sites e-commerce : il interroge chaque visiteur comme un vendeur en boutique, puis lui recommande son top 3. |
| Description longue | Seeckr est un assistant IA qui pose quelques questions à vos visiteurs, comme le ferait un vendeur en boutique, puis leur recommande les produits de votre catalogue qui correspondent à leur besoin. Là où un chatbot attend la question du visiteur, Seeckr pose les siennes : le visiteur décrit sa situation, sans avoir à connaître le nom du produit. Il reçoit un top 3, avec un score de compatibilité honnête et une explication qui dit pourquoi chaque produit est fait pour lui. Un visiteur qui hésitait repart avec le bon produit : vous vendez davantage, avec moins d'erreurs d'achat. Vous lisez aussi chaque conversation, avec les mots de vos clients : ce qu'ils cherchent et ce qui les fait hésiter, de quoi bâtir vos personas et vos accroches de campagne. Seeckr s'installe avec une ligne de script, se connecte à toutes les plateformes e-commerce (Shopify, WooCommerce, PrestaShop, sites sur mesure) et parle neuf langues. |
